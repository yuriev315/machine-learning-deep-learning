# NPU 格式

`.rknn`、`_edgetpu.tflite` 已实际编译；`.dlc`、`.hef`、`.om` 需要需登录下载的 SDK。这些产物都绑定具体芯片，不能跨设备使用。

完整对照见 [model_format_matrix.csv](../../manifests/model_format_matrix.csv)。
