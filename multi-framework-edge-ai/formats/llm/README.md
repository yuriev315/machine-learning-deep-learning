# LLM 与专用格式

GGUF 是 llama.cpp 和 ggml 生态的格式，主要用于 LLM，**不是通用神经网络交换格式**。语音用 whisper.cpp 的 ggml 模型单独验证。

完整对照见 [model_format_matrix.csv](../../manifests/model_format_matrix.csv)。
